# Hospital Payroll Management System

## 📌 Project Overview

Hospital Payroll Management System is a Java-based web application developed using JSP, Servlets, and Bootstrap.  
The system helps hospitals manage employee payroll records efficiently.

This project allows administrators to:
- Add hospital employees
- Manage salary records
- Delete employee records
- View all employee payroll details

Employees can:
- Search salary details using Employee ID or Name
- View detailed salary reports
- Print salary slips

# 🧮 Salary Formula

Net Salary =  
(Hours Worked × Hourly Rate + Allowances) − Deductions
